# Runtime and test dependencies for the sqlgenie exercise.
#
# sqlglot is the one that needs justifying. This service's security boundary is a
# rewrite of generated SQL, and a rewrite needs a parse tree: the table a query reads
# can be two CTEs and a lateral join below the surface, and no amount of pattern
# matching on text finds it reliably. A regex-based rewriter would be a rewriter that
# works on the shapes its author thought of, which is the one property a security
# control must not have.
#
# It is pure Python with no transitive dependencies, which is what makes it acceptable
# here when numpy and pandas are not acceptable in the other exercises. That ban exists
# so the statistics stay checkable by hand; SQL parsing is not arithmetic.
#
# There is no LLM SDK. The model is a recorded fake -- see src/sqlgenie/llm/ -- so this
# service makes no network calls at all and the test suite cannot accidentally bill
# anybody.
fastapi>=0.110,<1
uvicorn[standard]>=0.27,<1
pydantic>=2.6,<3
psycopg[binary]>=3.1,<4
sqlglot>=25.0,<31

httpx>=0.27,<1
pytest>=8.0,<9
