# Runtime and test dependencies for the ragqa exercise.
#
# No numpy, no sklearn, no vector database, and no LLM SDK.
#
# The vector store is a few hundred chunks scanned linearly in pure Python -- see
# src/ragqa/rag/retriever.py. At this scale an exact scan is microseconds, and it means a
# retrieval test measures retrieval rather than the recall of an approximate index built
# from a seed nobody controls.
#
# The embedder is a hashed TF-IDF vectoriser standing in for an offline embedding job, so
# the corpus can be rebuilt by anyone with no credentials and no network. The model is a
# recorded fake keyed by question. Both choices are argued in the modules themselves.
#
# The consequence, stated plainly: this service makes no network calls at all, and its
# tests cannot accidentally bill anybody or fail because a vendor is down.
